# Дизайн будущего — лендинг канала

Лендинг для подписки на канал «Дизайн будущего» в мессенджере MAX.

## Как опубликовать на GitHub Pages

1. Создайте новый репозиторий на GitHub (например, `design-future-landing`)
2. Загрузите файл `index.html`
3. Откройте **Settings → Pages**
4. В разделе **Build and deployment** выберите Branch: `main` → Save
5. Через минуту сайт будет доступен по адресу `https://ВАШ_НИК.github.io/design-future-landing/`

## Важно

Откройте `index.html` и в блоке `<script>` замените ссылки:
- `CHANNEL_URL` — ссылка на ваш канал
- `AUTHOR_URL` — ссылка на ваш профиль
